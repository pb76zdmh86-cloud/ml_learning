        (4, 3) и (3,): справа 3 и 3 совпадают. Недостающее измерение слева считается 1, оно совместимо с 4.

        чтобы не возникала такая ошибка:ValueError: operands could not be broadcast together with shapes (4,3) (4,)

        Группирует квартиры по количеству комнат: однокомнатные,

2) Что означает столбик на первом графике и точка на втором?
        Один столбик показывает среднюю цену квартир с определённым
        количеством комнат.
        Одна точка показывает отдельную квартиру: её площадь

4) Почему шести квартир недостаточно для выводов обо всём рынке?
        Эти квартиры могут быть нетипичными: например, слишком дорогими.
        Их средняя цена может сильно отличаться
        от средней по рынку.

        Медиана — "задвижка", а не известная площадь квартиры.
        Мы рассчитали её по всем известным площадям в очищенной таблице.
        Настоящая площадь может отличаться от задвижки.
