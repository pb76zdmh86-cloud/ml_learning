1) Почему (4, 3) совместима с (3,), но не с (4,)?
        (4, 3) и (3,): справа 3 и 3 совпадают. Недостающее измерение слева считается 1, оно совместимо с 4.
        (4, 3) и (4,): справа 3 и 4 не совпадают, и ни один размер не равен 1 — операция невозможна
2)  Зачем нужен keepdims=True при вычитании средних строк?
        чтобы не возникала такая ошибка:ValueError: operands could not be broadcast together with shapes (4,3) (4,)
3)  Чем отличаются (x - minimum) / difference и x - minimum /difference?
        расставление приоритетов операций мат правило

        3)keepdims=True: сохранением формы (4, 1) для вычитания средних строк.
